# Flova（flova.tv）

> AI 原生的视频创作 Agent 平台

## 产品是什么

Flova 是一个 AI 原生视频创作 Agent 平台，定位为「你的专属 AI 视频创作 Agent」。用户用自然语言表达创作诉求（也可上传文本、图片、视频、音频作参考），由 Agent 多步规划执行，把项目从构思推进到成片，覆盖剧本、分镜、图片/视频/音频生成与剪辑时间线组装（[官方文档](https://flova.tv/zh-CN/docs/?flovatv=1)）。背后公司为雨舟科技（深圳）有限公司，由连续创业者郭列（脸萌创始人、曾将公司出售给字节跳动）于 2025 年创立，Flova.ai 于 2025 年 10 月上线（[腾讯新闻/36氪](https://view.inews.qq.com/a/20260728A0734P00)、[企查查](https://m.qcc.com/firm/3b6c47c7da1bd301a93177b7a9688c67.html)）。

## 核心功能

- 对话式 Agent 全流程创作：自然语言驱动剧本、分镜、素材生成到剪辑组装的完整链路（[官方文档](https://flova.tv/zh-CN/docs/?flovatv=1)）
- 集成全球主流图像、视频、音乐生成模型（含满血版 Seedance 2.5）与调度用语言模型（[腾讯新闻](https://news.qq.com/rain/a/20260812A078SL00)）
- Storyboard 故事板工作台：支持人机同屏、手动操作与局部 AI 生成并行（[官网](https://flova.tv/)）
- Skill 机制：把创作习惯、审美和流程写成可复用的 Skill，Agent 按同一标准执行；官方称「全球首个开源视频 Skill」（[官网](https://flova.tv/)）
- 项目级记忆：持续记录剧本、分镜、素材与剪辑状态，可反复修改中间环节、版本可回退（[官方文档](https://flova.tv/zh-CN/docs/?flovatv=1)）
- 多端同步：移动端与 Web 数据互通，大型项目建议在 Web 端创作（[官网](https://flova.tv/)）

## 流量表现

- 榜单数据：trending 榜第 58 名，月访问量 166.1K，月增长 127.5K（环比约 +330%），首次被发现于 2026-03-18。
- 域名 flova.tv 注册于 2026-03-18（[阿里云 WHOIS](https://wanwang.aliyun.com/whois/flova.tv)），与榜单首次发现时间一致，说明该站为面向中文市场的全新落地站点，增长基数低、增速快。此前主站为 flova.ai（Semrush 显示其 2026 年 7 月访问量 60.5 万，[来源](https://www.semrush.com/website/flova.ai/overview/)）。
- 增长可能原因（推测）：2026 年 7 月公司宣布超 8000 万美元天使轮融资（红杉中国、IDG、云九资本），同期国内媒体（36氪、腾讯新闻、51CTO 等）密集报道「Flova + Seedance 2.5」组合，叠加免费积分与半价模型的拉新策略，带动 flova.tv 快速起量。

## 商业模式

积分制订阅 + 充值模式（[官方订阅文档](https://www.flova.ai/docs/zh-CN/Subscription-Credits)）：

- 免费计划：初始 400 积分（登录 200 + 每周刷新 200 + 探索激励 200）
- 会员订阅：月度积分包，宣称「会员低至 4.6 折，满血 Seedance 2.0 官方半价低至 ¥0.67/秒」，含去水印导出、商用授权
- 变现补充：会员可额外充值积分，支持支付宝订阅；有邀请奖励、超创/活动奖励积分等运营机制

## 竞争格局

- 即梦（字节跳动）：背靠剪映生态与 Seedance 自研模型，流量与生态优势大，但缺少 Flova 的 Skill 化 Agent 工作流叙事
- 可灵（快手）：同样主打视频生成大模型 + 创作者生态，偏模型能力而非全流程 Agent 平台
- Vidu（生数科技）：聚焦人物与场景一致性、连续化内容生产（[钛媒体](https://www.tmtpost.com/8090914.html)），与 Flova 的「商业制片总导演」定位形成差异
- Runway / Pika：海外视频生成标杆，面向专业工作流，但对中文用户与本土模型（Seedance 等）的整合不如 Flova

## 情报判断

Flova 的跑量逻辑是「强创始人背书（郭列）+ 巨额天使轮融资 + 绑定满血版 Seedance 模型做性价比拉新」三箭齐发，属于资本与媒体驱动的典型爆发式增长。Skill 化 Agent 与项目级记忆是其试图建立差异化的关键，长期留存取决于创作工作流能否真正沉淀用户，而非单纯积分补贴。值得持续观察：flova.tv 相对主站 flova.ai 的分流策略，以及补贴退坡后的留存数据。
