# PikpikGo（pikpikgo.com）

> 聚合主流大模型的一站式 AI 创作平台

## 产品是什么

PikpikGo 是一个浏览器端的一站式 AI 创作平台，把主流图像、视频大模型聚合在同一个工作区里，用户用一个统一的积分余额（credits）在所有模型间自由切换，无需分别订阅各家服务（[官网](https://pikpikgo.com/)）。团队/公司背景未在官网公开，定价页同时支持支付宝与微信支付，推测为面向全球市场的中国背景团队（待核实）。

## 核心功能

- **多模型聚合**：图像侧接入 OpenAI 的 GPT Image 2.5 / GPT Image 2、Google 的 Nano Banana Pro（Gemini 3 Pro Image），视频侧接入字节跳动的 Seedance 2.5 与阿里巴巴的 Wan 3，最高支持 4K 图像输出、30 秒 1080p 带声视频（[官网](https://pikpikgo.com/)）。
- **Creative Studio 无限画布**：在同一画布上拖拽、组合、迭代素材，支持图文视频混合创作。
- **AI Agent**：官方宣称可用一句话生成文案、图片、视频与分镜，可将单张产品图扩展为广告素材、社媒内容与落地页（[官网博客](https://pikpikgo.com/blogs)）。
- **统一积分体系**：一个 credit 余额通用于所有模型，订阅按月发放积分、当月未用完清零。
- **团队协作**：付费档含 100 席位的 team workspace 与 5–30 GB 素材存储。

## 流量表现

- 榜单数据：new 榜 rank 75，月访问量 40.6K，月增长 40.6K，首次被发现于 2026-08-03（数据来自 traffic.cv 榜单）。
- 月增长与月访问量完全相等，说明该产品上线后几乎从零起步，当前全部流量都是近一个月新增的，处于冷启动后的首轮放量期。
- 增长可能的原因（推测）：踩中 2026 年下半年 GPT Image 2.5、Nano Banana Pro、Seedance 2.5 等新模型发布的热点，「聚合最新模型」的 SEO/目录站投放策略起效——该产品已被 aibase、gptdemo、aitoolsdirectory 等多个 AI 工具目录收录（[aibase](https://top.aibase.com/topic/%E5%9B%BE%E7%89%87)、[AI Tools Directory](https://aitoolsdirectory.vip/item/pikpikgo)）。

## 商业模式

订阅制 + 积分制（[官网定价页](https://pikpikgo.com/)）：

- **Free**：$0，低速队列、仅基础模型、720P、每日限 3 张图。
- **Pro**：$100/年（约 $8.33/月），12,000 积分/年（按月发放 1,000），5 并发、4K 视频。
- **Max**：$300/年，36,000 积分/年，8 并发、15 GB 存储。
- **Ultra**：$1,000/年，120,000 积分/年，12 并发、30 GB 存储。
- 付费档均含无水印、商用授权；仅支持按年订阅（自动续费），另可单次购买积分；支持信用卡、支付宝、微信支付。

## 竞争格局

- **Pollo AI / Hailuo 类聚合站**：同样聚合多家视频模型按积分计费，PikpikGo 差异在于同时覆盖图像 + 视频 + Agent，并以无限画布为工作区。
- **Krea**：以实时生成画布见长，偏设计师向；PikpikGo 更偏营销素材与批量出图场景。
- **Runway**：视频生成标杆，生态与可控性更强，但模型仅限自家体系，价格高。
- **Freepik / Recraft**：素材平台 + AI 生成一体化，商用授权链路成熟，是 PikpikGo 争取付费用户的直接对手。

## 情报判断

PikpikGo 是典型的「模型聚合套利」型产品：不自研模型，靠第一时间接入各家最新旗舰模型 + 统一积分 + 年付订阅快速变现，增长高度依赖目录站收录和 SEO，门槛低、同质化严重，可持续性存疑。值得关注的是其 Agent + 无限画布的工作流尝试，若能把「聚合」升级为「创作工作流」，才有机会摆脱纯套壳定位。当前 40.6K 月访问体量尚小，需观察次月留存与续费信号。
