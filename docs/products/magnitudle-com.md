# Magnitudle（magnitudle.com）

> 每日视觉尺度估算游戏

## 产品是什么

Magnitudle 是一个免费的每日估算类网页游戏合集，由独立开发者 Teej 一人创建并通过 GriddleLink Games 发布（[官网 About](https://magnitudle.com/)）。核心玩法「Size It Up」：每轮给出一个蓝色参照物剪影和一个可缩放的目标剪影，玩家调整目标大小使其与参照物的真实比例相符，每天五轮、满分 500 分，估算误差在 6% 以内可得满分。另有数值估算玩法 Daily Question 等模式。

## 核心功能

- **Size It Up**：每日五轮视觉大小估算，拖动缩放剪影后锁定答案并揭晓真实尺寸（[官网](https://magnitudle.com/size-it-up)）
- **主题变体**：Size It Up: Pop Culture（虚构角色/物品）、Size It Up: Geography（地理形状与地点）
- **Magnitudle Daily Question**：每日一道真实世界数值估算题，提交一次猜测看接近程度（[magnitudle.com/daily](https://magnitudle.com/daily)）
- **Survival**：每周三开始的周挑战模式（官网 FAQ）
- **题库存档**：可游玩过往的 standard、Pop Culture、Geography 谜题
- 每日谜题按玩家本地时区零点刷新；浏览器直接游玩，免费，无需专业知识

## 流量表现

- 榜单数据：trending 榜第 2 名，月访问量 11.4M，月增长 11.2M，首次被发现 2026-03-02。
- 月增长（11.2M）几乎等于总访问量（11.4M），说明这是一个上线约 7 个月内从零爆发到千万级月访的新站，增长几乎全部由近期贡献。
- 增长可能的原因（推测，有公开迹象佐证）：
  - 主播与创作者带货：官网博客称 NorthernLion、Ludwig、ohnePixel、Joe Bartolozzi 等头部主播/创作者直播或录制过 Size It Up（[官网博客](https://magnitudle.com/blog/creators-playing-size-it-up)），这类传播是 Wordle 式每日游戏的典型爆发路径。
  - 每日一题 + 高分晒图机制天然适配社交媒体传播，站点在 Playlin、Alldle、Listdle、dailydle 等多个「.dle 游戏目录」中被收录，带来聚合流量（[Playlin](https://playlin.io/game/size-it-up/)）。
  - Wordle 带火的「每日游戏」品类红利仍在延续，视觉估算题材在同质化的文字猜谜中有差异化。

## 商业模式

官网未见任何定价、订阅或内购信息，所有公开游戏模式免费游玩。变现方式**未公开**；从站点结构推测（推测）可能依赖广告或未来增值功能，目前无直接证据。

## 竞争格局

- **Wordle 及「.dle」每日游戏家族**（Connections、Framed、Heardle 类）：同为每日一题模式，Magnitudle 的差异在视觉尺度估算而非文字/音频猜谜。
- **TimeGuessr / GeoGuessr**：真实世界知识 + 猜测玩法，但侧重地点猜谜，时长更长， Magnitudle 单局仅需几分钟。
- **Higher Lower Game**：数值比较猜测游戏，与 Daily Question 模式相近，但缺少视觉缩放交互。
- ** Neal.fun 类独立小游戏站**：同为个人开发者的病毒式网页玩具，Magnitudle 以每日更新机制强化回访。

## 情报判断

Magnitudle 踩中了「Wordle 式每日游戏」的长尾红利，用视觉尺度估算这一差异化玩法 + 头部主播自发传播实现了 7 个月从零到 11.4M 月访的爆发；一人团队、零变现信息意味着成本极低、增长质量依赖创作者流量与每日回访习惯。可持续性待观察：此类游戏的生命周期通常依赖品类热度与持续的模式扩展（Pop Culture、Geography、Survival 已是信号），变现路径缺失是最大未知数。
