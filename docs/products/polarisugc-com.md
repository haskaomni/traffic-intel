# Polaris（polarisugc.com）

> 面向电商的 AI UGC 广告视频生成工具

## 产品是什么

Polaris 是一款专为电商（ecommerce/DTC）打造的 AI UGC 广告生成工具，由 Maverick International Enterprises LLC（注册于美国怀俄明州 Sheridan）运营（[Imprint](https://polarisugc.com/imprint)）。用户粘贴产品图或产品链接，即可在几分钟内生成 UGC 风格的视频和图片广告。其差异化打法是通过 MCP 连接器接入 Claude，让用户直接在 Claude 对话里用自然语言下单生成广告，单条渲染约 20–180 秒，支持批量并行（[官网](https://polarisugc.com/)、[博客](https://www.polarisugc.com/blog/arcads-vs-icon)）。

## 核心功能

- 多模型广告生成：集成 Nano Banana Pro（图像）、Seedance 2.0、Kling 3.0 Turbo、Gemini Omni Flash 等模型生成视频/图片广告（[官网](https://polarisugc.com/)）
- Claude MCP 集成：在 Claude 对话中直接创建广告、发布到平台，支持批量生成与 ZIP 下载（[官网](https://polarisugc.com/)）
- AI Ad Clone：一键复刻竞品 winning ad；支持克隆自定义演员（custom actors）
- Auto Captions：自动添加任意风格的烧录字幕，字幕与口播对齐
- 配音与配乐：ElevenLabs Ultra 配音、Suno 音乐（[Pricing](https://www.polarisugc.com/pricing)）
- 免费工具引流：UGC 脚本生成器、广告 hook 生成器、ROAS 计算器，无需注册（[Tools](https://polarisugc.com/tools)）

## 流量表现

- 榜单数据：2026-07-10 首次被 traffic.cv 发现，登上 new 新品榜第 135 位，月访问量 10.3K，月增长 10.3K（即上线后首月流量几乎全部来自最近一个月）。
- 增长可能的原因（推测）：官网自称「$750M+ 广告消耗跑在 Polaris 生成的广告上」「2,400+ 创始人用户」，但无法独立核实；其博客大量发布「Arcads vs Creatify」「Arcads vs HeyGen」等竞品对比 SEO 文章（2026 年 5–7 月密集更新），叠加 Claude MCP 概念的热度，可能是早期流量的主要来源。未检索到 Product Hunt 上线或独立媒体报道，公开口碑信息极少。

## 商业模式

订阅制 + 积分（credits）模式，无免费试用，但首批 12 条广告免费、无需信用卡（[官网](https://polarisugc.com/)）：

- Starter：$49/月（标价 $70），1,500 积分/月，约 36 条 AI 视频
- Creator：$98/月（标价 $140），5,000 积分/月，约 121 条视频
- Max：$350/月（标价 $500），17,500 积分/月，约 426 条视频
- 所有套餐含「Unlimited」慢速免费渲染（排队、低一档分辨率、不耗积分）
- 另有推荐返佣计划：推荐新客可获其付款的 30%（[Pricing](https://www.polarisugc.com/pricing)）

## 竞争格局

- Arcads：以 AI 演员口播 UGC 视频为核心，Polaris 则是从产品图出发的全流程广告工作室（[Polaris 博客自述](https://polarisugc.com/blog/polaris-vs-arcads)，对比视角有立场倾向，待核实）
- Creatify / Icon：同为 AI 广告生成工具，Polaris 的区分点是「跑在 Claude 里的 ecom 原生引擎」
- HeyGen：以数字人口播视频见长，非电商广告专用

## 情报判断

Polaris 踩中了两个风口：AI UGC 广告（电商素材生产刚需）和 Claude MCP 生态（借 Claude 用户池获客）。首月 10.3K 访问说明其 SEO 对比文 + MCP 概念组合有一定拉新能力，但体量仍小、几乎无第三方报道，「$750M 广告消耗」等宣传数字无法核实，团队信息仅有壳公司注册地址，可信度待观察。值得关注的点：MCP 分发是否能在 Arcads、Creatify 等竞品跟进前建立壁垒。
