# Forge（forge.art）

> 对话式 AI 无限画布与营销视频生成工具

## 产品是什么

Forge 是 Tensor.Art 旗下的 AI 创意产品，面向内容创作者和电商营销人员；[Tensor.Art 官方活动页](https://tensor.art/blackboard/tensorforgecup)将其标注为“Forge by Tensor.Art”。用户在无限画布中向 Agent 描述创意，由 Agent 生成内容，也可通过 Skill 上传产品图和卖点制作营销视频（[Forge 官网](https://forge.art/)）。本次检索未找到可信的具体上线日期、独立团队或融资信息，均待核实。

## 核心功能

- **Agent 无限画布**：用自然语言描述想创作的内容，由 Agent 在画布中生成（[官网](https://forge.art/)）。
- **Viral Video Recreation**：上传产品图，将热门视频复刻为包含自己产品的版本（[官网](https://forge.art/)）。
- **UGC Video**：把产品和核心卖点转化为自然的 UGC 视频（[官网](https://forge.art/)）。

## 竞争格局

- **FLORA**：同样以 AI 画布为核心，但更强调多模型、团队协作与可扩展工作流；Forge 更突出 Agent 和现成营销视频 Skill（[FLORA 官网](https://flora.ai/)）。
- **Creatify**：更专注从产品页批量生成、测试和优化视频广告；Forge 则把 UGC 视频放在通用创意画布中（[Creatify 官网](https://creatify.ai/)）。

## 情报判断

Forge 的优势在于把 Tensor.Art 的创作生态与 Agent 画布结合，并用爆款复刻、UGC 广告等明确场景降低使用门槛。当前 11.9K 月访问量和 new 榜第 123 名仍属早期体量，能否持续取决于主品牌导流后的留存与付费转化；详细收费、上线时间和团队信息仍需继续核实。
