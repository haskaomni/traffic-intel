# Capafy（capafy.ai）

> AI Skill 交易市场，创作者可变现

## 产品是什么

Capafy 是一个面向 Skill-based Agent 的交易市场（marketplace）。开发者与领域专家把自己的工作流封装成 AI Skill（含 `SKILL.md`、脚本、参考资料等），上架为可付费使用的 Agent；用户可以在浏览器中直接运行，或在自己已有的 Agent Client（Claude Code、Codex、Hermes、OpenClaw）里调用。平台负责发现、支付、云端执行、凭证保护与交付，创作者可定价并从使用中持续获得收益。据 [Blockchain News](https://blockchain.news/ainews/capafy-launches-skill-marketplace-pays-per-run) 报道，该产品于 2026 年 5 月在 X 上公开发布；团队与公司背景未见公开披露，待核实。

## 核心功能

- **Skill 市场浏览与搜索**：按分类发现各领域专家制作的 Agent，卡片展示用途、定价、评分与销量（来自官网首页）
- **浏览器内零安装运行**：云端执行的 Skill 无需本地配置，点开即用（来自官网）
- **Agent Client 集成**：安装 User Skill 后可在 Claude Code、Codex、Hermes、OpenClaw 中直接调用平台上的 Agent（来自 [官方博客](https://capafy.ai/blog/what-is-capafy)）
- **闭源执行保护 IP**：选择 "Run on Capafy" 时 Skill 在平台云端运行，用户只拿结果，创作者的 prompt、脚本与方法论不外泄（来自官网及 [TestingCatalog 报道](https://www.testingcatalog.com/capafy-launches-new-ai-skills-marketplace-for-creators/)）
- **创作者发布与变现工具**：提供 Publisher Skill 辅助打包上架，支持订阅（日/周/月/年）、按小时、一次性买断三种收费方式（来自官方博客）
- **在售 Agent 覆盖多领域**：短视频生成与 Hook 优化、股票/赛事分析、SEO 写作、简历优化、占卜娱乐等，价格从免费到 US$29 不等（来自官网首页）

## 流量表现

- 月访问量 164.2K，月环比增长 134.6K（增长约 455%），2026-04-17 首次被发现，登上 traffic.cv trending 榜第 49 名。
- 时间点与其 2026 年 5 月的公开发布吻合，增长很可能来自上线初期的曝光与媒体转载（Blockchain News、TestingCatalog、Futurepedia、ai-directories 等均有收录/报道）——属推测。
- Agent Skill 概念（Anthropic 推动的开放标准）本身处于热度上升期，平台作为早期交易市场对创作者和尝鲜用户有双向吸引力——属推测。

## 商业模式

双边市场抽佣模式：创作者对 Skill 自主定价，支持订阅（日/周/月/年）、按小时计费、一次性买断（下载源码）三种模式，平台提供支付、托管与云端执行基础设施。平台自身抽成比例未公开。官网在售 Agent 定价示例：US$1.99–20.99/周、US$2.99–6.99/日、US$3–5/小时，另有大量免费/免费试用 Skill 用于引流。

## 竞争格局

- **Anthropic 官方 / 开源 Skill 生态（GitHub 等）**：免费开源分发，无变现与 IP 保护机制；Capafy 主打闭源执行 + 付费交易。
- **GPT Store（OpenAI）**：面向 ChatGPT 生态的 GPTs 市场，锁定单一平台；Capafy 跨 Claude Code、Codex、Hermes、OpenClaw 多个 Agent Client。
- **MCP 服务器目录（如 Smithery、mcp.so）**：偏工具/接口分发的目录站，无完整的付费与云端执行闭环。
- **Poe（Quora）**：bot 创作者变现平台，面向消费端聊天场景；Capafy 面向专业工作流与 Agent 用户。

## 情报判断

Capafy 踩中了 Agent Skill 标准兴起的时间窗口：开源生态里优质 Skill 缺乏变现与 IP 保护，平台用「闭源云端执行 + 订阅分成」补上这个缺口，定位清晰。风险在于市场规模依赖 Skill 生态本身的普及度，且当前在售商品以短视频、股票分析、占卜等偏娱乐/流量型 Skill 为主，高质量专业供给能否持续沉淀待观察。短期内上线红利带来的高增长明显，能否留存取决于双边市场冷启动后的复购率。
