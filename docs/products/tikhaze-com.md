# Haze Method（tikhaze.com）

> TikTok 画质优化与检测工具

## 产品是什么

Haze Method（前身为 Haze Tools）面向希望减少 TikTok 二次压缩损失的创作者，提供视频优化、直接发布和发布后画质检测。用户上传 MP4 或 MOV 文件后，工具修改 MP4 容器与元数据而不重新编码画面，再下载回 TikTok 发布或直接从站内上传。[官方指南](https://tikhaze.com/guides/what-is-haze-method)

服务条款显示其从菲律宾运营，是独立于 TikTok 的工具；具体团队成员未公开。[服务条款](https://tikhaze.com/terms)

## 核心功能

- **Optimize**：通过修改视频容器和元数据进行优化，不重新编码画面；支持最高 4K、120 fps，单文件上限 1 GB。
- **Upload**：可直接发布到 TikTok，并设置文案、封面和隐私选项。
- **Check**：粘贴 TikTok 链接即可查看实际播放分辨率、帧率、码率及 For You 状态。
- **多种处理引擎**：官网列出 Lite、Classic 和 Max，免费用户也可使用；另提供可选的 HandBrake 重编码。
- **扩展与 API**：提供 Chrome、Firefox 扩展及面向开发者的视频优化 API。[功能说明](https://tikhaze.com/guides/what-is-haze-method)

## 流量表现

- 增长可能来自 TikTok 创作者对高清发布的明确需求，以及每周免费积分和 Discord 社群带来的传播；这是基于官网产品机制的推测，暂无渠道数据佐证。

## 商业模式

采用免费额度加订阅制：Member 免费，每周提供 30 Haze Credits；Plus 为 **4.99 美元/30 天**，每周 100 积分；Premium 为 **9.99 美元/30 天**，不限处理次数并标注 3 天免费试用。网站还销售积分和开发者 API 使用包，具体续费条款以结账页为准。[官网定价](https://tikhaze.com/)

## 竞争格局

- **TikTok 原生 HD 上传**：无需额外工具，但不提供 Haze 的独立优化与发布后参数检测。
- **HandBrake**：通用本地视频转码工具；Haze 更聚焦 TikTok 上传流程，并主打不重编码的元数据处理。
- **CapCut**：覆盖剪辑与导出全流程；Haze 则专注上传前后的画质优化和验证。

## 情报判断

Haze Method 把“TikTok 上传后变糊”这一具体痛点做成了优化、发布、验证闭环，免费周额度也降低了尝试门槛。其持续性高度依赖 TikTok 的压缩与上传机制，服务条款也承认平台变化可能导致优化方法失效，因此后续应重点观察功能稳定性与付费口碑。
