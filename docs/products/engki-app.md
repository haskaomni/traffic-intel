# Engki（engki.app）

> 面向印尼用户的英语间隔重复卡片学习站

## 产品是什么

Engki 是一个浏览器英语学习工具，以印尼语界面、英语词汇卡组和间隔重复复习为主。官网搜索摘要介绍其提供每日句子、Again / Good / Easy 复习反馈，并把学习记录保存在用户设备上；团队、公司和正式上线时间均未见可靠公开信息（[官网](https://engki.app/)）。

## 核心功能

- **间隔重复卡片**：通过 Again、Good、Easy 反馈安排英语卡片复习。
- **公开分级卡组**：首页列出 Beginner A1、A2 各 5 套、300 张卡片，以及印尼语标注的基础和中级词汇系列。
- **印尼语词汇内容**：Kosakata Dasar 与 Kosakata Menengah 各 13 套，分别展示 932 和 984 张卡片。
- **每日句子与本地记录**：搜索摘要显示提供 daily sentences，学习数据保存在设备端，具体同步能力待核实。

## 竞争格局

- **Anki**：通用间隔重复工具，卡片和插件生态强大，但配置门槛更高。
- **Duolingo**：以游戏化课程和连续学习机制见长，内容体系比 Engki 更完整。
- **Quizlet**：提供共享卡组与多种学习模式；Engki 的差异更偏轻量浏览器体验、印尼语内容和设备端保存。

## 情报判断

Engki 用轻量间隔重复和印尼语本地化切入明确的英语学习市场，产品理解成本低，但公开信息较少，内容深度、留存和运营主体都不透明。当前增长是否可持续无法仅凭榜单判断，后续更应观察课程更新、回访机制及真实用户口碑。
