# Grid Maker（gridmakerapp.com）

> 免费在线绘画网格生成器，SEO 驱动

## 产品是什么

Grid Maker 是一个面向绘画爱好者、学生和美术教师的免费在线工具：用户在浏览器里自定义网格尺寸、线宽、颜色、透明度，可叠加参考照片，生成并下载绘画用网格（PNG/JPG/PDF），用于网格法（grid method）临摹与比例缩放（[官网](https://www.gridmakerapp.com/)）。开发者/公司背景未公开，官网无 About、无署名，公开渠道也无团队信息（待核实）。域名注册于 2026-07-05（[WHOIS](https://www.whois.com/whois/gridmakerapp.com)），与榜单 first_seen 日期完全一致，是一个全新的站点。

## 核心功能

- 自定义网格：调整网格大小、线宽、颜色与透明度
- 参考图叠加：上传参考照片，直接在图上叠加网格后导出
- 多种网格类型：正方形、矩形、三角形、等轴测（isometric）网格
- 多格式导出：PNG / JPG / PDF，可打印或在绘图软件中使用
- 免注册、免安装，即开即用，官方宣称「100% free, no signup required」
- 配套 [Blog](https://www.gridmakerapp.com/blog) 发布网格画法教程，明显用于 SEO 引流
