# MakeTag（maketag.app）

> 快速创建自定义 Discord 标签

## 产品是什么

MakeTag 是帮助 Discord 用户制作并佩戴个性 Server Tag 的网页服务，团队信息未公开。用户用 Discord 登录，设置字母、徽章和颜色，再加入服务预先配置好的服务器，即可在 Discord 个人资料中选择该标签。[官网](https://maketag.app/)

## 核心功能

- 自定义标签字母、徽章与颜色，每个账号可创建一个标签。
- 自动提供已配置服务器的邀请，无需用户自己搭建服务器。
- 提供公开标签目录，可浏览并加入其他标签对应的服务器。
- 免费 Demo 让用户体验流程；搜索公开页面显示 MakeTag Full 提供永久、无广告标签。
- 服务器主可生成推广链接，用户通过该链接制作标签时会先加入其服务器，并提供访问、加入和留存统计。[推广页](https://maketag.app/promo/)

## 流量表现

- 榜单月访问量 **51.6K**，月增长 **51.6K**；2026-10-05 首次被发现，目前位列 `new` 榜第 **57**。
- 自定义身份标识具有分享动力，而推广链接把「领标签」和「加入服务器」绑定，可能形成服务器主主动导流的循环；这是基于官网机制的增长推测，实际渠道待核实。

## 商业模式

官网提供免费 Demo；公开搜索摘要显示 MakeTag Full 以永久标签和无广告为卖点，但可访问页面未公开价格与付费方式。推广链接本身免费，服务器主仍需自行承担在外部社区投放广告的费用。

## 竞争格局

- **Discord 原生 Server Tags**：官方直接提供服务器标签，MakeTag 用预建服务器简化个人获取流程。
- **自建 Discord 服务器**：管理员可自行配置标签和社群，自由度高，但需要搭建与运营。
- **Top.gg 标签目录**：侧重发现已有服务器和标签，MakeTag 同时覆盖标签制作与佩戴流程。

## 情报判断

MakeTag 把 Discord 的平台能力包装成低门槛的身份装扮工具，并嵌入了面向服务器主的邀请增长机制。短期跑量逻辑清楚，但标签依赖 Discord 功能与规则，且加入多个赞助服务器可能影响用户体验；完整版定价和留存数据尚未公开。
