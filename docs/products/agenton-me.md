# AgentOn（agenton.me）

> AI Agent 打工赚钱的赏金任务平台

## 产品是什么

AgentOn 是一个面向 AI Agent 经济的任务网络平台，2026 年 6 月 8 日正式上线（据 [GlobeNewswire 新闻稿](https://www.globenewswire.com/news-release/2026/06/08/3308179/0/en/agenton-officially-launches-kicking-off-a-100-000-bounty-campaign-for-ai-agents-and-users.html)，发稿地为香港，团队与融资信息未公开）。平台连接两端：项目方（Merchant）发布 Quest 任务并设置 USDC 奖金，AI Agent 自主发现任务、提交成果，经审核后获得链上奖励。用户可以让自己的 Agent（如 OpenClaw、Claude Code、Codex）通过 API 自动注册并接单，口号是「AI takes the work. You take the credit.」（[官网 Docs](https://agenton.me/docs)）。

## 核心功能

- Task Marketplace：Agent 浏览并接取任务（内容创作、社媒互动、推文推广、数据分析、社区运营等），提交成果后链上自动结算 USDC（[官网](https://agenton.me/)）
- Agent Marketplace：让专业化 Agent 能力可被发现、可验证，对接真实需求（[官网](https://agenton.me/)）
- AgentOn Credit：随 Agent 身份绑定的链上信誉体系，信誉越高越容易获得项目方认可和任务（[官网 Docs](https://agenton.me/docs)）
- XP 等级与全球排行榜：每日签到、任务提交累积经验值，提升账号权重（[官网 Docs](https://agenton.me/docs)）
- 绑定 X 账号与 FluxA 钱包：解锁高级任务、接收奖励并提现 USDC 至 Base 链钱包（[官网 Docs](https://agenton.me/docs)）
- AgentOn SDK / 协议层：基于 x402、ERC-8004 等 Agent 经济标准构建（[官网](https://agenton.me/)）

## 流量表现

- 榜单数据：new 榜 rank 60；月访问量 30.1K，月增长 30.1K（增长量与访问量持平，说明几乎全部流量为当月新增）；首次被发现 2026-05-18。
- 增长时间线与官方动作吻合：平台于 2026-06-08 正式上线，并同步开启 10 万美元赏金活动（6 月 8 日至 7 月 8 日，超 30 个项目参与，[GlobeNewswire](https://www.globenewswire.com/news-release/2026/06/08/3308179/0/en/agenton-officially-launches-kicking-off-a-100-000-bounty-campaign-for-ai-agents-and-users.html)）。据此推测，访问增长主要由上线赏金活动的空投/赚钱预期驱动。官网 Quests 页显示平台已有 10,226 个注册 Agent、1,216 个日活 Agent、奖池总额约 47,163 USD、122 个任务（[官网 Quests 页](https://agenton.me/quests)，为抓取时快照，实际数字随时间变动）。

## 商业模式

官网未公开定价页。从机制看：项目方付费发布 Quest 并注入奖金池，Agent 完成任务获得 USDC，平台大概率从任务发布或奖金结算中抽成（推测，未见官网明示）。面向 Agent 侧免费注册，完成指定任务可获得奖励。

## 竞争格局

- Galxe / Zealy：成熟的人类用户 Web3 任务平台，AgentOn 的差异是任务执行者从人类转向 AI Agent，且结算链上自动化。
- Kaito（InfoFi）：以社媒内容质量和影响力为核心的注意力激励网络，AgentOn 更偏通用任务市场 + Agent 身份信誉。
- Virtuals Protocol ACP：Agent 间自主商业协作协议，AgentOn 与之思路相近但形态是任务悬赏市场，并兼容 x402、ERC-8004 等开放标准。

## 情报判断

AgentOn 卡位「Agent 经济基础设施」叙事，用真金白银的赏金池做冷启动，上线首月即拿下 30.1K 访问，说明「Agent 打工赚钱」的钩子对 Web3 人群有效。但当前任务大量为刷量型推广与买币任务（如官网 Quests 页的 Buy & Hold 任务），流量对补贴高度依赖，可持续性存疑；值得观察的是赏金活动结束后（7 月 8 日）的留存，以及其链上信誉层能否沉淀为真正的护城河。团队背景与融资未公开，透明度待核实。
