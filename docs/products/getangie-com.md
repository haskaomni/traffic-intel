# Angie（getangie.com）

> 异地恋情侣的实时双人游戏与约会中心

## 产品是什么

Angie 是一个面向异地恋（LDR）情侣的实时互动平台：两人在不同地点打开同一个「房间」，在同一秒一起玩十余款双人游戏和约会活动，而非各自发消息。官网自述产品源于开发者为自己的异地女友 Angie 做的约会小站，后开放为公开产品，支持 Web、Android、iOS，浏览器直接使用无需安装（来源：[官网首页](https://getangie.com/)）。从服务条款适用印尼法律、支持 Midtrans 印尼盾付款来看，团队很可能位于印尼，开发者身份未公开（来源：[Terms](https://getangie.com/terms)）。

## 核心功能

- **Online Photobooth**：韩式 인생네컷（Life4Cuts）风格线上双人拍照亭，共享倒计时在两块屏幕上同时拍摄，永远免费（来源：[官网](https://getangie.com/)）。
- **Know Me Quiz / Love Match**：情侣默契问答与性格匹配测试，双方私密作答、同时揭晓并给出匹配分数，Quiz 为最热门玩法。
- **AI 裁判类游戏**：Couples Debate、Couples Court、Fashion Show 等由 AI 打分裁决的对抗玩法。
- **协作类游戏**：Draw Together 实时同画、The Lab 学习约会（数学/科学对战或合作）、Our Future 未来规划约会并生成愿景板。
- **Create a Date**：用户可自建嵌入游戏的幻灯片式约会流程。
- **Print Studio / 周边打印**：双人实时在同一画布设计 T 恤、卫衣、托特包（300 dpi、全球配送）；拍贴可印成冰箱磁贴，$12/个，满 3 件 8 折，一个订单可分寄两人地址（来源：[官网](https://getangie.com/)、[Print Shop](https://getangie.com/shop)）。

## 商业模式

免费 + 订阅 + 周边电商的混合变现（来源：[Terms](https://getangie.com/terms)）：

- **免费层**：Photobooth 永远免费，每个游戏有每日/终身免费额度；免费下载的拍贴带水印。
- **Premium 订阅**：Web 端海外 $10/2 周（Stripe 自动续费），另有 $5/7 天试用转订阅；印尼区 Rp 99.000/31 天一次性购买（Midtrans，不自动续费）。App 内为 $9.99/月或 $79.99/年（年付含 7 天试用和伴侣 Premium 通行证）。
- **终身买断**：Couple's Gift Set $79 / Angie Unlimited Rp 379.000，含终身 Premium + 伴侣邀请码。
- **单次解锁**：$3 / Rp 20.000 解锁某次 session 的无水印 HD 拍贴和 booth 视频。
- **实体周边**：磁贴 $12/个、服装印花定制，全球配送。

## 竞争格局

- **Paired / Agapè**：主流情侣关系 App，主打每日问答与情感课程，但偏异步沟通，无实时同屏游戏。
- **Lovewick / Couple Game**：情侣问答与破冰卡牌类 App，玩法类似 Know Me Quiz，但缺少实时房间与拍贴玩法。
- **Web 端派对游戏（如 Jackbox、Gartic Phone）**：实时同玩机制相似，但面向多人聚会而非情侣双人约会场景。
- Angie 的差异点：专为「两地双人同一秒」设计，把实时游戏、韩式拍贴和实体纪念品打印串成一条从线上约会到实物留存的链路。

## 情报判断

Angie 切中异地恋这一情绪浓度高、付费意愿明确的细分人群，用「实时同屏」做出与一般情侣 App 的差异化，且拍贴/磁贴自带社交传播与电商变现，商业模式比一般工具站更立体。风险在于：增长高度依赖 viral 传播，新鲜感消退后留存待观察；双人场景意味着拉新需两人同时激活，门槛与裂变系数并存。值得持续跟踪其订阅转化（尤其 $10/2 周这一偏激进定价）与周边电商占比。
