# MiniMax H3（minimaxh3.ai）

> 套壳 MiniMax H3 模型的第三方 AI 视频生成站

## 产品是什么

minimaxh3.ai 是一个以 MiniMax 开源视频模型 H3（又称 Hailuo 3.0 / 海螺 3）为卖点的在线 AI 视频生成站，支持文生视频、图生视频、多素材参考生成和指令式视频编辑。需要注意：该站**并非 MiniMax 官方产品**——同域名的公开 GitHub 仓库明确声明是「独立第三方工作室」，与 MiniMax / 海螺 AI 无隶属关系（[minimaxh3-site-kit](https://github.com/bbwdadfg/minimaxh3-site-kit)、[minimaxh3](https://github.com/bbwdadfg/minimaxh3)），且存在 minimaxh3.art / minimaxh3.tv 等同族域名，是典型的品牌词套壳 SEO 站群。

## 核心功能

- 多模态参考生成：单次请求最多混用 9 张图片、3 段视频、3 条音频，保持角色一致性与风格统一
- 文生视频 / 图生视频：提示词最长 7000 字符，输出 5–15 秒、24 FPS、最高 1440p 带立体声视频
- 指令式视频编辑：一句话换角色、换背景、改布光、改台词，未编辑部分保持像素级稳定
- 语音克隆：提供参考音频即可让角色用该声音说新台词
- 多画幅：21:9 / 16:9 / 4:3 / 1:1 / 3:4 / 9:16
- 站内同时聚合 Seedance 2.5、GPT Image 2、Nano Banana 等其他模型，按积分计费

## 流量表现

- 月访问量 11.4K，月增长 11.4K（纯新增），new 榜第 140 名，2026-07-30 首次被发现，时间上与 MiniMax H3 模型开源发布（2026 年 8 月前后）高度吻合。
- 增长逻辑清晰：蹭新模型发布的搜索热度，用「模型名 + 域名」抢占品牌词流量。流量盘子很小，说明品牌词红利被多镜像站（.art/.tv/.ai）和官方渠道稀释。

## 商业模式

积分制订阅，按年付打折：Lite $14.95/月（年付 $178.8）到 Max $99.95/月（年付 $1,198.8）四档，生成按积分消耗（MiniMax H3 每次 30+ 积分起，年付套餐用 premium 模型可省 30%），付费档含商用授权；注册送免费积分可试用。来源：[官网定价区](https://minimaxh3.ai/)。

## 竞争格局

- MiniMax 官方（minimax.io / 海螺）：原厂渠道，模型更新最快、价格更低。
- minimaxh3.art / minimaxh3.tv：同族镜像站，同一运营方的站群内部竞争（依据：GitHub 声明指向 .art 站）。
- faymas.net、openmov.ai 等聚合站：同样接入 H3 类模型，但以「多模型一站聚合」而非单一品牌词获客。

## 情报判断

这是「新模型发布 → 抢注品牌词域名 → 套壳变现」链路的标本案例：H3 开源带火搜索词，第三方快速建站接住流量，用积分订阅赚差价。风险点明显——品牌词有商标争议风险，且模型一旦开放官方免费入口，套壳站价值迅速归零。对情报站的价值在于：它出现的本身就是「MiniMax H3 在 C 端有真实搜索热度」的信号。
