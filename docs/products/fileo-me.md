# Fileo Compress（fileo.me）

> 图片压缩全程在浏览器本地完成

## 产品是什么

Fileo Compress 是 fileo.me 提供的本地优先图片压缩工具，面向需要减小网页、聊天或商品图片体积，同时不愿把文件上传到第三方服务器的用户。图片在浏览器标签页内解码和重新编码，官网明确称像素不会发送到 fileo.me；团队背景与上线时间未公开（[官网](https://fileo.me/)、[About](https://fileo.me/about)）。

## 核心功能

- **纯浏览器压缩**：支持 JPEG、PNG、WebP、GIF，文件不上传服务器，可用浏览器 Network 面板自行验证。
- **批量处理**：每批最多 20 个文件、单文件 8 MB；超长边会缩至 8,192 像素以内。
- **质量与目标体积控制**：可调 quality、填写目标 KB，并选择 JPEG、WebP 或 PNG 输出。
- **前后对比**：并排预览原图和压缩结果，同时显示两边字节数，便于判断画质损失。
- **元数据清理**：通过 canvas 导出时会去掉 EXIF、GPS 和相机序列号，不添加水印（[隐私政策](https://fileo.me/privacy)）。

## 流量表现

- 榜单数据：new 榜第 27 名，月访问量 73.6K，月增长 73.6K，首次被发现于 2026-09-20，本期榜单增长量与当前月访问量相同。
- 增长可能原因（推测）：「不上传」「移除 EXIF/GPS」覆盖了对隐私敏感的高意图需求，站内的格式和质量科普内容也有利于搜索获客；公开检索几乎未见独立报道，真实增长渠道待核实。

## 商业模式

当前工具无每日额度，About 页明确表示没有通过 Pro 方案解锁本机算力的设计，基础压缩可直接使用。变现方式**未公开**；隐私政策称压缩器本身目前不设置广告 cookie，未来若加入测量或广告脚本会先更新政策（[About](https://fileo.me/about)、[隐私政策](https://fileo.me/privacy)）。

## 竞争格局

- **Squoosh**：同样在浏览器本地处理图片并强调隐私，与 Fileo Compress 的产品重叠度最高。
- **TinyPNG**：成熟的云端压缩和开发者 API 服务，自动化集成更强，但文件需要上传。
- **ImageOptim**：本地桌面压缩工具，适合批量和固定工作流，但需要安装。

## 情报判断

Fileo Compress 把计算放在用户设备上，既形成隐私卖点，也降低了服务端处理成本，图片压缩又是长期存在的搜索需求，具备持续获取工具流量的基础。不过 Squoosh 等免费替代品已经很强，且 Fileo 当前缺少清晰变现；8 MB 文件上限及 HEIC/AVIF 兼容性也会影响部分真实使用场景。
