# Cola Skill（colaskill.com）

> 精选 AI Agent Skills 目录站

## 产品是什么

Cola Skill 是 MarsWave（火星回响，ListenHub 与 ColaOS 背后的团队）运营的 Agent Skills 精选目录站，口号为「Curated skills for better ways to get things done」。它收录各类开源 Agent Skills（基于开放 Agent Skills 协议的技能包），每个条目附说明与建议提示词，用户可将技能安装到 Claude Code、Codex、Cursor 等编程/办公 Agent 的 skills 目录中使用（[官网](https://colaskill.com/)、[ColaOS 研究站介绍](https://colaos.org/zh/colaos-skills)）。整站提供英文与简体中文双版本。

## 核心功能

- 精选 Skill 目录：覆盖 AI 短剧制作（shuohao-skills）、中文网文写作（chinese-novelist-skill）、UI 设计（oil-ui、taste-skill）、简历优化（resumeskills、vibe-resume-skill）、小红书选品（xhs-product-picker）等（[官网](https://colaskill.com/)）
- 9 大分类浏览：创意与设计、增长与营销、产品与技术、个人生意、职场办公、自我提升、教学、研究与分析等（[ColaOS 研究站](https://colaos.org/zh/colaos-skills)）
- 按创作者组织的视图，如 Baoyu、gingiris 等作者的技能合集页（[官网条目](https://colaskill.com/baoyu-skills/)）
- 每个 Skill 独立详情页，写明功能、用法与示例提示词，支持中英双语阅读（[示例](https://colaskill.com/zh/writing-dna-skill/)）
- 与 MarsWave 官方技能仓库联动（[github.com/marswaveai/skills](https://github.com/marswaveai/skills)），并提供飞书/微信社群入口

## 流量表现

- 登上 traffic.cv trending 榜第 78 名：月访问量 134.6K，月环比增长 109.9K（约为前期基数的 5 倍以上），首次被发现于 2026-06-24。
- 增长可能原因（推测）：2026 年 Agent Skills 生态（Claude Code / Codex skills 机制）热度上升，目录类聚合站吃到搜索与社区流量；团队主线产品 ColaOS 在 2026 年上半年获虎嗅等媒体关注（[虎嗅报道](https://m.huxiu.com/article/4853847.html)），品牌外溢带动目录站访问；双语站点同时覆盖中文 AI 用户群，可能也是放量因素。

## 商业模式

会员制：新用户添加微信客服可领取会员体验，产品页提及「¥20 会员试用」；站点导航含「定价」「充值积分」入口，推测存在会员订阅加积分充值两种变现方式（具体价格档位未在公开页面抓取到，待核实）。部分技能为第三方免费开源，目录本身充当流量入口与分发渠道。

## 竞争格局

- awesome-claude-skills / GitHub 上的开源 Skills 合集：免费、纯列表，Cola Skill 胜在精选、详情页和中文本地化。
- Smithery / MCP 目录类站点（如 mcp.so）：聚合 MCP 工具而非 Agent Skills，用户重合度高。
- 各 Agent 官方技能市场（Claude Code / Codex 内置 skills 机制）：官方渠道权威但无中文精选策展。
- 提示词分享社区（如 LangGPT 类中文提示词站）：形态相似但偏 prompt 而非可安装的技能包。

## 情报判断

Cola Skill 本质是 MarsWave 围绕自家 ColaOS/ListenHub 生态做的一个低成本流量与社区入口：借 Agent Skills 协议走红的时间窗口，用精选目录卡位「中文用户找技能」这一需求。背靠有融资（200 万美元天使+轮）且已盈亏平衡的团队（[虎嗅](https://m.huxiu.com/article/4853847.html)），运营可持续性强；但目录站门槛不高，长期价值取决于能否把流量沉淀进会员和自家产品生态，值得跟踪其会员转化与官方技能仓库的开源动向。
