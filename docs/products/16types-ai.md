# 16Types（16types.ai）

> 以人格测试引流的订阅制成长计划

## 产品是什么

16Types 是塞浦路斯公司 EMOTIONYX LTD 运营的一个「人格测试 + 个人成长订阅」网站（[隐私政策](https://16types.ai/privacy-policy)、[服务条款](https://16types.ai/terms)）。用户先免费做一套 16 型人格测试（"Discover your true Personality Type"），测完后被引导购买「16Types Growth Plan」——一个基于人格类型生成每日练习的个性化成长计划。同一公司还运营姊妹产品 IQ Booster（iqbooster.org，脑力训练订阅），两者条款、代码、漏斗结构高度复用（官网 JS bundle 内交叉引用）。

## 核心功能

- 免费 16 型人格测试，作为整个漏斗的入口
- 16Types Growth Plan：根据人格类型和进度生成个性化每日活动与练习
- AI-powered habit and mindset coach：AI 驱动的习惯与心态教练
- 每日挑战（daily challenges）：短时每日任务，随用户成长动态调整难度
- 脑力训练小游戏：记忆、专注、处理速度、逻辑思维等 6 个游戏类别
- 多语言落地页：英、德、日、韩、荷、挪、瑞典、简体中文等，明显的全球化投放结构

## 流量表现

- 月访问量 239.5K，环比增长 +233.1K，几乎全部流量都是本月新增（上月基数约 6K）；2026-04-20 首次被 traffic.cv 发现，目前位列 trending 榜 #51。
- 上线约 3 个月即放量，增长曲线符合典型的「广告买量型 quiz 漏斗」：人格测试是社媒广告的高转化素材，多语言落地页 + 低价试用订阅是成熟打法。具体投放渠道（Meta/TikTok 等）未公开，此判断为基于产品结构的推测。
- 值得注意的是，其 ScamAdviser 条目（funnel.16types.ai 子域）被标记为低信任分（[ScamAdviser](https://www.scamadviser.com/check-website/funnel.16types.ai)），这类「试用转订阅」漏斗在消费者投诉平台上常见争议。

## 商业模式

订阅制。提供免费试用期（默认 7 天，试用需付小额费用），试用到期未取消则自动转为付费订阅，按月 / 每 4 周 / 按年自动续费，通过 Stripe 收款；订阅费用一经收取不予退款（[subscription policy](https://16types.ai/terms)，官网条款明示 "no refunds"）。具体价格在结账页动态展示，官网未公开标价。同一主体以同样模式运营 IQ Booster，说明这是一套可复制的订阅漏斗模板。

## 竞争格局

- 16Personalities（NERIS Analytics）：免费 MBTI 测试的绝对头部，靠付费报告变现，不做订阅锁。
- BrainManager / 123test 等：同类「测试引流 + 付费报告」站点，模式相近但规模更大、历史更久。
- Lumosity / Impulse 等脑力训练 App：与 16Types 的 Growth Plan 游戏部分重叠，但走 App Store 订阅，非网页广告漏斗。
- 差异点：16Types 用「人格测试」而非 IQ 测试做钩子，主打自我成长叙事，并用同一套基础设施复用到 IQ Booster 等多个品牌。

## 情报判断

典型的订阅漏斗产品：人格测试素材投放 → 7 天低价试用 → 自动续费，3 个月内从近乎零跑到 24 万月访问，说明付费投放 ROI 已跑通且正在多国复制。可持续性取决于获客成本与退订/拒付率——此类模式复购弱、口碑风险高（ScamAdviser 低信任分、退款条款苛刻），但母公司显然在批量复制同一模板（16Types + IQ Booster），值得作为「AI 落地页订阅漏斗」赛道的样本持续跟踪。
