# imgico（imgico.com）

> 免费图片前后对比滑块工具

## 产品是什么

imgico 是一个免费的 before/after 图片对比滑块（image comparison slider）工具，自我定位为已停止服务的同类产品 imgsli 的替代者（见 [AlternativeTo 收录页](https://alternativeto.net/software/imgi-co/about/) 与官网 [/imgsli 页面](https://imgico.com/imgsli)）。用户拖入两张（最多十张）图片，用可拖动的滑块对比差异，发布生成永久短链接分享，或嵌入自己的网站。核心使用场景是游戏 Mod / 材质包与原版对比、AI 超分与 DLSS 画质对比、修图前后对比、渲染与压缩测试。开发者/团队身份未公开，官网无 About 页面。

## 核心功能

- 拖入 2–10 张图片，用滑块对比，两图像素级对齐（锁定同一位置，只动差异部分）
- 一键发布生成永久短链接，观看者无需注册即可交互拖动
- 支持 iframe 嵌入，把实时对比滑块放进博客、文档或 Mod 页面
- 离线模式：纯浏览器本地对比，文件不上传、不重编码
- 双侧标签命名（如 Native 4K / Performance mode），随链接对所有观看者生效
- 附带 EXIF 元数据读取/抹除工具（浏览器端运行）

## 流量表现

- 榜单数据：月访问量 30.1K，月增长 +28.8K（几乎全部为新增量），2026-08-19 首次被发现，登上 traffic.cv new 榜第 65 名。
- 增长可能的原因（推测）：imgsli 停摆后留下大量存量需求（Reddit、游戏社区中 imgsli 链接曾是画质对比的事实标准），imgico 直接做了 [/imgsli](https://imgico.com/imgsli)、[/imgdiff](https://imgico.com/imgdiff) 等 SEO 承接页，吃下迁移流量；同时 AI 超分、DLSS 画质对比内容在社区持续产出，工具被链接传播自带增长。

## 商业模式

官网明确写明完全免费：无限上传、私有链接、自定义链接名、文件夹、单图 50 MB 上限，无需注册、无付费档位，仅靠「一个赞助位广告」（a single sponsored placement）变现。页面文案中曾提到「Pro 可设私有链接」，与 Pricing 段「全部免费」表述不一致，推测是从付费模式转为赞助模式后文案未清理（待核实）。

## 竞争格局

- imgsli：曾经的事实标准，目前已停止服务/不再可用，imgico 正是其直接替代者。
- JuxtaposeJS（Knight Lab）：开源嵌入组件，需自行托管，面向开发者而非普通用户。
- imgdiff：轻量图片对比工具，功能相近，imgico 做了专门的 SEO 承接页。
- 一般图床 + 拼图对比：无交互滑块，体验差距明显。

## 情报判断

imgico 的增长是典型的「继承者红利」：踩着 imgsli 留下的真空，用 SEO 承接页 + 免费无门槛策略快速吃掉存量需求，月增 28.8K 几乎全部来自冷启动后的承接流量。可持续性取决于 imgsli 迁移流量耗尽后的留存——工具本身无账号体系、无粘性设计，但「链接永久有效 + 嵌入传播」有一定复利效应。值得关注的点：赞助位广告模式能否覆盖图床成本，以及是否会重启 Pro 付费档。
