# Meowdoku（meowdoku.app）

> 猫咪主题的浏览器逻辑解谜游戏

## 产品是什么

Meowdoku 是一款猫咪主题的区域逻辑解谜游戏，玩法源自 N 皇后（N-Queens）约束问题：在网格的每个彩色区域、每行、每列各放一只猫，且猫之间不能相邻（包括对角）。原作手游由 Oakever Games（乐信圣文）发行，2026 年 4-5 月上线后迅速登顶多国 App Store 免费游戏榜（[GameDropDaily](https://gamedropdaily.com/mobile/meowdoku/)、[Similarweb](https://www.similarweb.com/top-apps/google/new-zealand/games/top-free/)）。meowdoku.app 是该玩法的浏览器网页版，打开即玩、无需下载，主打无广告、无体力限制、无计时器的纯净体验。

## 核心功能

- 浏览器内即点即玩，支持桌面、平板、手机，无需下载安装（[官网](https://meowdoku.app)）
- 超过 15,000 个关卡，从 5×5 小棋盘渐进到高难度棋盘
- X 标记系统：标记不可能放置猫的格子，辅助逻辑推导
- 逻辑导向的提示系统：先检查用户错误（错误的猫、错误的 X、冲突），再指向可推理出的下一步，而非直接给答案
- 无下载、无体力限制、无限提示、无计时器、无打断广告
- 内置规则教学与解题策略指南（强制猫、排除法、锁定区域、计数法）

## 竞争格局

- **Meowdoku 手游官方版（Oakever Games）**：iOS/Android 原生应用，含广告变现，App Store 免费游戏榜第一、4.81 星 8.5 万条评价（[GameDropDaily](https://gamedropdaily.com/mobile/meowdoku/)）。
- **LinkedIn Queens**：该玩法的直接原型，依托 LinkedIn 平台的每日谜题，已被验证为病毒式传播机制（[Capermint 分析](https://www.capermint.com/blog/game-like-meowdoku-brain-puzzle/)）。
- **meowdoku.club / meowdoku.games 等同类网页版**：同一波蹭热度的克隆站，玩法雷同，差异化极小，拼的是 SEO 排名。
- **经典数独 / Nonogram 类网页游戏**：用户重叠度高，但 Meowdoku 的规则更简单、单局更短。

## 情报判断

这是一个典型的「热点玩法 + SEO 流量站」产品：借 Meowdoku 手游爆发的品牌搜索量，用免费、无广告的浏览器版本快速承接流量，18.4K 的纯新增月访问印证了这一打法短期内有效。但流量高度依赖原作热度与搜索排名，本身无内容壁垒、无用户资产，一旦手游热度退潮或官方推出自己的网页版，流量可持续性存疑。值得关注的点：N 皇后类「每日逻辑谜题」赛道在 2026 年的整体热度，以及这类克隆站的变现路径。
