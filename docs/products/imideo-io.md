# iMideo（imideo.io）

> 独立开发者的一站式 AI 视频生成平台

## 产品是什么

iMideo 是一个多模型聚合的在线 AI 视频/图像生成平台，由一名自称前端开发兼产品设计师的独立开发者（indie maker）创立，官网 About 页称创办于 2024 年（[imideo.io/about](https://imideo.io/about)）。它把 Veo 3、Sora 2、Seedance、Nano Banana、Seedream、Z-Image 等第三方模型统一封装在一个产品里，面向不会剪辑的创作者和中小商家，通过文字、图片或已有素材生成短视频，并提供一个对话式的 "AI Video Agent" 来代选模型和执行编辑。

## 核心功能

- Text-to-Video / Image-to-Video / Video-to-Video：文字、静图或已有片段生成视频，最高 1080p+
- Reference-to-Video / 多图合成：上传 2-14 张图片，AI 将不同主体融合进同一视频场景
- Face Swap / Head Swap / Body Swap：照片和视频中换脸、换头、换身
- 素材清理工具：Video Watermark Remover（去水印）、Video Upscaler（最高 4K）、添加音效
- AI Video Agent：用对话描述需求，Agent 自动选择模型、报价并执行生成
- 争议功能：定价页列出 "Undress Video (AI Clothes Remover)"，属灰色地带功能（[imideo.io/pricing](https://imideo.io/pricing)）

## 流量表现

- 榜单数据：trending 榜第 88 名，月访问量 108.9K，月环比增长 80.7K（约 +286%），首次被发现于 2026-07-10
- 注意：本次榜单抓取到的页面描述是隐私政策页文本（"collects, uses, stores, and protects data..."），并非产品定位描述，调研已按官网首页为准甄别
- 增长可能原因（推测）：产品 2026 年 3 月起在 Peerlist、SideProjectors 及多个 AI 工具目录站（Toolfolio、hrefgo、Creati.ai 等）持续铺量收录（[Peerlist](https://peerlist.io/jsdasww593/project/imideo--allinone-ai-video-generator)、[SideProjectors](https://www.sideprojectors.com/project/76497/imideo-ai-powered-video-generator)），聚合 Veo 3 / Sora 2 等热门模型关键词利于 SEO 截流；换脸/去水印/Undress 类工具本身搜索需求大，可能是流量主力（推测，待核实）

## 商业模式

Credits 积分制 + 订阅。免费用户仅送少量试用积分，结果 24 小时删除；一次性积分包 300-2000 积分（有效期 1 个月）；月付 Lite $12.90 / Pro $29.90 / Ultimate $49.90；年付折后 Lite $7.49/月、Pro $14.99/月、Ultimate $24.99/月，年付积分不过期。单条视频成本宣称低至 $0.07-$0.25（[imideo.io/pricing](https://imideo.io/pricing)）。本质是转售第三方模型 API 的中间层，赚差价。

## 竞争格局

- Pollo AI / Hailuo 类聚合站：同样聚合多家视频模型，功能高度重叠，拼模型上新速度和价格
- Kling / Runway / Pika：原厂模型平台，品牌和画质更强，但单模型、单价高
- FlexClip / Vmake：偏在线剪辑 + AI 工具箱，面向更轻量的营销视频需求
- iMideo 差异点：换脸/换身/去水印/Undress 等"特效工具"更全，且有对话式 Agent 降低使用门槛

## 情报判断

典型的"模型聚合套利"产品：独立开发者低成本套壳 Veo 3 / Sora 2 等热点模型，靠 SEO 和工具目录铺量快速起量，三个月冲到月访 10 万级说明截流策略有效。可持续性存疑——无自研模型壁垒，原厂降价或收紧 API 都会直接挤压利润；Undress 类灰色功能虽能带量，但存在支付通道和合规风险，是观察其能否长期存活的关键信号。
