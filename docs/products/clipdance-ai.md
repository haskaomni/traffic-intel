# ClipDance（clipdance.ai）

> 聚合多家大模型的 AI 视频生成平台

## 产品是什么

ClipDance 是一个独立第三方 AI 视频创作平台，自身声明与 ByteDance 无隶属关系，而是通过 API 接入各家视频生成模型，提供统一的浏览器创作工作区（[官网定价页声明](https://clipdance.ai/pricing)）。用户用文本或图片即可生成带同步音频的 1080p 视频，无需拍摄和剪辑软件。平台以字节跳动的 Seedance 2.0 为招牌模型，同时聚合 MiniMax H3、Wan 3.0、Kling V3、Veo 3 等多家引擎（[Progressive Robot 评测](https://www.progressiverobot.com/2026/08/30/clipdance-ai-video-generator-review/)）。

## 核心功能

- Text-to-Video / Image-to-Video：文本或图片生成视频，原生同步生成对话、音效和背景音乐
- 多参考输入：单个项目最多支持 12 个参考文件（图片、视频片段、音频），控制风格、运动与构图
- 浏览器内视频编辑：上传素材后用自然语言描述修改，可保留原声或替换 AI 音效
- Beat-Sync：上传音轨后自动让镜头切换与运动踩点，面向音乐视频和短视频
- Lip-Sync：支持英语、日语、韩语、中文等 8+ 语言的角色口型同步
- 两步模板流水线：预置「参考图 + 视频」两步模板，约四分钟产出成品（以上均来自[官网](https://clipdance.ai)）

## 流量表现

- 榜单数据：new 榜 rank 53，月访问量 61.6K，月增长 61.6K，首次被发现于 2026-08-11。月增长与月访问量持平，说明流量几乎全部是在上榜当月新增，属于典型的冷启动爆发形态。
- 增长可能原因（推测）：2026 年 8 月恰是 Seedance 2.0 发布的窗口期，官网顶部横幅即以「Seedance 2.0 Released」引流，踩中了模型发布带来的搜索流量红利；同时 8 月 16 日当周在 Launch Igniter 等新品发布平台集中曝光（[LaunchIgniter Week 34](https://launchigniter.com/weekly-launches/week-34-2026)），博客也在 8 月中旬密集发布教程内容，符合 SEO + 新品发布的组合打法。

## 商业模式

订阅制 + 积分制，年付 8 折（[Progressive Robot 评测](https://www.progressiverobot.com/2026/08/30/clipdance-ai-video-generator-review/)）：

- Free：免费额度，免信用卡，标准画质（付费项如 1080p、去水印、商用授权被锁定）
- Pro：$24/月（年付）或 $29.99 月付，500 积分/月，约 125 条 5 秒基准视频
- Business：$64/月（年付）或 $79.99 月付，2,500 积分/月，支持最高 4K、镜头控制、15 秒时长
- Enterprise：$160/月（年付）或 $199.99 月付，8,000 积分/月，含 API 与专属支持
- 另有按量付费积分包，100 积分 $12.99 起

## 竞争格局

- Runway：编辑管线最完整，但价格高（约 $95/月），且无原生音频
- Pika：快速便宜的短视频生成，偏娱乐化短片段，缺少多镜头叙事
- Kling / Hailuo 官方应用：模型原厂工具，单模型深度功能更强，但需逐家开户付费
- Dreamina：Seedance 模型的官方入口，与 ClipDance 的第三方聚合定位直接对位

ClipDance 的差异在于「一个订阅、多家引擎」：用户可在同一积分池下随时切换模型，避免为每家模型单独订阅（[Progressive Robot 评测](https://www.progressiverobot.com/2026/08/30/clipdance-ai-video-generator-review/)）。

## 情报判断

ClipDance 的本质是「AI 视频模型的聚合二道贩子」，靠 Seedance 2.0 发布的流量窗口快速起量，聚合 + 统一积分池的模式对内容团队有真实的运营价值。可持续性存疑：其流量高度依赖上游模型的热度周期，且作为无隶属关系的第三方 API 转售方，存在上游条款变动的连续性风险。值得关注的点：它能否在模型热度退潮后靠模板流水线、博客 SEO 内容沉淀下自然流量，以及官方平台（如 Dreamina）是否会挤压其生存空间。
