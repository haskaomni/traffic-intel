# Make.design（make.design）

> AI 一句话生成网站与营销设计

## 产品是什么

Make.design 是一款 AI 设计生成工具：用户用自然语言描述需求，产品在几秒内生成 landing page、平面设计、营销素材等视觉稿，并可通过聊天式对话持续修改。官网强调「不需要设计团队也能把想法变成设计」，主要面向没有专职设计师的创业者、营销人员和内容创作者（来源：[make.design 官网](https://make.design/)）。团队背景与上线时间公开信息极少，待核实。

## 核心功能

- **Prompt 生成设计**：一句话描述生成 landing page、UI 概念稿、平面与营销视觉，默认输出「现代化、偏转化导向」的设计风格。
- **聊天式编辑**：通过后续对话改写标题、调整布局、更新按钮、更换配色，或把同一创意延展为整套营销素材。
- **多格式适配**：同一 prompt 可产出面向 Website、Ads、Post、Graphic、Marketing 等不同场景的成品。
- **品牌一致性**：支持导入品牌色与素材，使生成结果贴合品牌。
- **分享与导出**：可发送在线预览、导出干净素材，并支持团队协作迭代。
- 生成内容可用于商业项目（官网 FAQ 明确允许商用）。

## 流量表现

- 月访问量 60.4K，月增长 52.8K，首次被榜单发现于 2026-05-30，出现在 traffic.cv 的 trending 榜单第 114 位。
- 增长占当前访问量的约 87%，说明近期流量几乎全部由新访客贡献，处于明显的爬坡早期。
- 可能原因（推测）：AI 设计生成赛道 2025-2026 年热度持续走高，加上 $9/月低门槛定价与 3 天免费试用，容易被 Product Hunt / 社媒导流带动；但具体流量来源渠道未见公开数据，待核实。

## 商业模式

订阅制 + 积分（credits）模式（来源：[官网 Pricing](https://make.design/)）：

- **Starter**：$9/月，75 张图/月，含网站设计、平面设计、营销素材生成与聊天式修改；3 天免费试用含 30 credits。
- **Pro**：$25/月，200 张图/月，增加 Advanced Reasoning、优先渲染队列、新功能抢先体验。
- **Max**：$50/月（首月 $30），400 张图/月，增加长上下文记忆、实验性功能与优先支持。

计费细则：每次设计生成消耗 2 credits，多数工具与编辑操作消耗 1 credit。

## 竞争格局

- **Canva Magic Design**：模板生态与品牌管理更成熟，Make.design 胜在纯 prompt 驱动的快速出稿。
- **v0 / Figma AI**：偏 UI 原型与可落地的代码/组件，面向设计师与开发者；Make.design 面向非设计人群，直接出视觉成品。
- **Relume**：聚焦网站信息架构与 wireframe 生成，Make.design 覆盖面更宽（广告图、社交帖、营销物料）。
- **Higgsfield / 各类 AI Design Generator**：同质化严重，Make.design 的差异化主要靠域名心智与「聊天改稿」体验。

## 情报判断

Make.design 踩中「AI 一键生成设计」的大众需求，低客单价 + 免费试用是典型的新品跑量组合，短期增速可观。但该赛道拥挤、生成质量壁垒不高，复购和留存才是能否持续的关键；52.8K 的月增长若主要来自一次性曝光，可持续性存疑。值得关注的点：是否能从「生成图片稿」进化到可上线的真实页面，以及商用授权是否带来 B 端付费。
